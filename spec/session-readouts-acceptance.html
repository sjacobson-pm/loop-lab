Session readout helpers

Provide two independent, pure JavaScript helpers for future session readouts. Each helper owns its own module and colocated tests; neither needs application wiring or a shared export file.

Acceptance rules

Export formatSessionCount(count). For a nonnegative safe integer, return "1 session" when count is 1, otherwise return the decimal count followed by " sessions" (including "0 sessions"). For any other input, throw RangeError.
Export formatElapsedTime(totalSeconds). For a nonnegative safe integer number of seconds, return elapsed time as h:mm:ss: hours are unpadded and may exceed 24, while minutes and seconds are always two digits from 00 through 59. For example, 0 is "0:00:00", 59 is "0:00:59", 60 is "0:01:00", and 3661 is "1:01:01". For any other input, throw RangeError.
